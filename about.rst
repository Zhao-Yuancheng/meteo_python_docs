   <section class="ma-block" id="ma-project">
     <div class="ma-sec-head">
       <span class="ma-kicker">About the Project</span>
       <h2>项目缘起</h2>
       <p>一次「朋辈互助、知识沉淀」的暑期社会实践</p>
     </div>
     <div class="ma-story-grid">
       <div class="ma-story-card">
         <h3>
           <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M4 19.5A2.5 2.5 0 0 1 6.5 17H20"/><path d="M6.5 2H20v20H6.5A2.5 2.5 0 0 1 4 19.5v-15A2.5 2.5 0 0 1 6.5 2z"/></svg>
           从 49 天前的一个念头说起
         </h3>
         <p>2026 年 7 月 13 日，期末考试的铃声刚落，兰州大学大气科学学院 8 名 2025 级本科生聚到一起，发起「气象学科编程互助知识库建设与朋辈助学实践」。我们在自己的学习里踩过太多坑：语法明明背了，报错却看不懂；图明明画出来了，却不知道哪里不规范。于是我们决定——<b>把这些经验沉淀成一套面向全院新生的编程知识库</b>。</p>
         <p>49 天里，团队采用<b>任务认领制</b>，把全部工作拆分为 67 个独立任务单元，自主完成了需求调研、顶层设计、内容生产、平台开发到部署上线的全过程：10 章主线教程把「Python 基础、气象数据处理、气象数据可视化」串成一条线，配上概念动画、术语参考、实战练习与常见问题排查，并以一份贯穿全站的「兰州气温观测数据分析」实战项目收束——让你学一章、进一步。</p>
         <p>如今你正在浏览的<b>云笺 CloudDocs</b>，就是这次实践的全部交付。它的每一章正文、每一帧动画、每一条 FAQ，都出自刚从新手村走出来的我们之手。</p>
       </div>
       <div class="ma-idea-card">
         <h3>
           <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M9 18h6M10 22h4M12 2a7 7 0 0 0-4 12.7c.6.5 1 1.4 1 2.3h6c0-.9.4-1.8 1-2.3A7 7 0 0 0 12 2z"/></svg>
           为什么叫「云笺」
         </h3>
         <blockquote>云，是我们的学科；笺，是可以传递、可以批注的小页纸张。云上之笺——写给后来人的学习手记。</blockquote>
