第 3 章练习：分支、循环与条件
==============================

配套 :ref:`tut-flow` 正文。每题给出**参考答案**与**提示**，先自己动手写，再对照参考。

.. seealso:: 配套正文：:doc:`/user_guide/basics/flow`　·　术语参考：:doc:`/api/ch03_terms`

💡 **通用易错提示**：``if``、``for``、``while`` 语句末尾**必须加冒号 ``:``**；循环、分支内部代码需要**统一缩进**（推荐 4 空格）；计数器初始化放在循环**外部**；``while`` 循环记得更新条件变量，防止无限死循环。

第 1 题 气温等级判定（if 分支）
--------------------------------

给定某日气温，规定：

- ``t ≥ 30``：高温
- ``20 ≤ t < 30``：舒适
- ``10 ≤ t < 20``：偏冷
- ``t < 10``：寒冷

编写程序，输入气温，输出对应的气温等级。

**参考答案**：

.. code-block:: python

   t = float(input("请输入气温(°C)："))
   if t >= 30:
       print("高温")
   elif t >= 20:
       print("舒适")
   elif t >= 10:
       print("偏冷")
   else:
       print("寒冷")

> 💡 提示：用一连串 ``elif >=`` 即可形成无缝隙阶梯，无需写成 ``20 <= t < 30``。

第 2 题 统计高温天数（for 循环遍历）
-------------------------------------

列表 ``temp_list = [28, 31, 22, 15, 8, 33, 25]`` 代表一周每日气温。高温标准：``≥ 30 ℃``。遍历列表，统计高温天数和总天数，打印输出结果。

**参考答案**：

.. code-block:: python

   temp_list = [28, 31, 22, 15, 8, 33, 25]
   count_high = 0
   total = len(temp_list)
   for t in temp_list:
       if t >= 30:
           count_high += 1
   print(f"总天数：{total}，高温天数：{count_high}")

> 💡 提示：``len(temp_list)`` 在循环外算一次即可，不必每次循环都调；``+= 1`` 是计数器累加的标准写法。

第 3 题 while 循环找首日超阈值
------------------------------

气温序列 ``temps = [18, 21, 24, 27, 32, 35]``，阈值设 30 ℃。使用 ``while`` 循环，找出第一个大于等于 30 ℃ 的下标位置，输出该下标；若全部不满足，输出"未出现"。

**参考答案**：

.. code-block:: python

   temps = [18, 21, 24, 27, 32, 35]
   i = 0
   n = len(temps)
   while i < n:
       if temps[i] >= 30:
           print(f"首个超阈值下标：{i}")
           break
       i += 1
   else:
       print("未出现")

> 💡 提示：``while...else`` 中 ``else`` 只在循环没有被 ``break`` 中断时执行，天然适合"找东西—找不到就报未出现"的场景。

第 4 题 嵌套循环处理多气象站点
------------------------------

.. code-block:: python

   stations = [
       [22, 25, 28],   # 站 1 连续 3 天
       [16, 19, 23],   # 站 2 连续 3 天
       [30, 32, 29]    # 站 3 连续 3 天
   ]

``stations`` 为 3 个气象站，每个子列表存储该站点连续 3 天温度。使用双重嵌套循环，遍历全部站点每一天温度，统计全部数据中 ``≥ 30 ℃`` 的数据总个数。

**参考答案**：

.. code-block:: python

   stations = [
       [22, 25, 28],
       [16, 19, 23],
       [30, 32, 29]
   ]
   cnt = 0
   for site in stations:
       for t in site:
           if t >= 30:
               cnt += 1
   print("全部高温总个数：", cnt)

> 💡 提示：外层循环遍历"站点"，内层循环遍历该站点的"每一天"；注意缩进层次——内层循环的代码块要再缩进 4 空格。

第 5 题 综合题：气温等级 + 统计
--------------------------------

现有多站温度数据：``data = [[27, 31, 14], [33, 18, 22]]``。嵌套循环遍历每个站点每一天温度，输出每一个温度对应的气温等级，同时统计全部数据中高温（``≥ 30``）的总天数。

**参考答案**：

.. code-block:: python

   data = [[27, 31, 14], [33, 18, 22]]
   high_total = 0
   for site in data:
       for t in site:
           if t >= 30:
               print(f"{t} → 高温")
               high_total += 1
           elif t >= 20:
               print(f"{t} → 舒适")
           elif t >= 10:
               print(f"{t} → 偏冷")
           else:
               print(f"{t} → 寒冷")
   print("全部高温总天数：", high_total)

> 💡 提示：整数序列 ``[27, 31, 14]`` 直接用于循环；``elif`` 自上而下，判断一次即可，无需写 ``20 <= t < 30``。
