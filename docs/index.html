气象 + Python 编程文档#

欢迎来到兰州大学大气科学学院编程社区的 气象 + Python 语言 编程文档。 本站仿照 Matplotlib 官方文档体系组织，覆盖 Python 基础、气象数据处理与气象数据可视化三大模块， 并提供可在线运行的代码示例——在每个代码块点 ▶ 运行，即可在悬浮运行器里执行。

快速开始

安装 Conda 与 Python，画出第一张气象图。

Python 与 Conda 简介
在线运行器

点代码块右上角"运行"按钮，浏览器里直接跑 Python。

常见问题 Q&A

三大内容模块#

  • 模块一 Python 编程基础：Conda、数据类型、分支循环、函数与作用域、面向对象与高级语法。

  • 模块二 气象数据处理：NumPy 计算、Pandas 分析、Xarray 多维数据。

  • 模块三 气象数据可视化：Matplotlib 绘图、Cartopy 地图绘图。
