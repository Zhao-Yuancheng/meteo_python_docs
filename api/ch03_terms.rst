第 3 章术语：分支、循环与条件
==============================

配套 :ref:`tut-flow` 正文使用。每个词条 = 一句话定义 + **生活类比** + **代码示例** + **易混淆点**。本章术语围绕"让程序做选择、重复做事"展开，理解它们你才能写出"会思考"的气象程序。

.. seealso:: 配套正文：:doc:`/user_guide/basics/flow`　·　配套练习：:doc:`/tutorials/basics/ch03_practice`

.. glossary::

   条件表达式
      用于判断真假的表达式，返回布尔值 ``True`` / ``False``，作为 ``if`` 分支的判断依据。它可以是比较（``temp >= 35``）、逻辑组合或成员判断。

      **生活类比** —— "如果下雨，就带伞"——"下雨"就是条件表达式，成立就执行对应动作。防洪预警里"未来 24 小时降雨量 ≥ 50 mm"，也是一条条件表达式。

      .. code-block:: python

         temp = 36.2
         if temp >= 35:            # temp >= 35 就是条件表达式
             print("发布高温预警")

      **易混淆点** —— ① ``=`` 是赋值，``==`` 才是相等判断，``if temp = 35:`` 会语法报错；② 条件表达式结果一定是布尔值，但 ``0``、``0.0``、``""``、``[]`` 等空值在判断时视作假，其余视作真，所以 ``if temps:`` 表示"列表非空才执行"。

   循环变量
      在循环过程中不断被赋新值的变量，控制循环次数或代表当前遍历到的元素。

      **生活类比** —— 上课点名用的\ **序号**：每念完一位同学序号就加 1，这个序号就是循环变量，它"代表"当前正在处理的那个人。

      .. code-block:: python

         temps = [28, 31, 22]
         for t in temps:           # t 就是循环变量，依次取 28、31、22
             print(t)

      **易混淆点** —— ① 循环结束后循环变量仍保留最后的值，``for t in temps:`` 跑完后 ``t`` 仍是最后一项，不是未定义；② 变量名可任意取但要有意义，``for t in temps`` 比 ``for x in temps`` 更能表达"这是温度"。

   迭代
      重复执行一段代码，逐一遍历序列中的每一个元素，完成重复处理工作。``for`` 循环的本质就是迭代。

      **生活类比** —— 清点货架上的全部货物，一件一件依次查看处理，这个逐个处理的过程就是迭代。气象里对 30 天逐日气温逐日求平均，就是迭代。

      .. code-block:: python

         week = [28.1, 29.4, 31.2]
         total = 0
         for t in week:            # 迭代列表，逐日累加
             total += t
         print(total)              # 88.7

      **易混淆点** —— ① 可迭代对象 vs 迭代器：列表、字符串、字典都是\ **可迭代对象**\（能一次性给出元素的容器），迭代器是"一次吐一个"的指针，初学者掌握"可迭代对象能被 ``for`` 遍历"即可；② 迭代 ≠ 索引：迭代是"逐个取元素"，索引是"按下标取特定元素"，迭代不关心下标除非用 ``enumerate``。

   缩进
      Python 用空格缩进划分代码的从属关系，标识某段代码属于循环或分支的内部。同层次的代码必须使用相同数量的缩进。

      **生活类比** —— 作文段落开头空两格，代表本段内容归属于上一个主题。缩进就是告诉 Python"这段代码是 ``if`` 里面的人"还是"站在外面等结果的人"。

      .. code-block:: python

         if temp >= 35:
             print("高温")         # 缩进 4 空格：属于 if 内部
         print("判断结束")         # 无缩进：属于 if 外部，一定会执行

      **易混淆点** —— ① 同一代码块内缩进不一致会报 ``IndentationError``，VS Code 默认 Tab 转 4 空格，建议统一；② 不要混用 Tab 和空格，Python 3 中两者混用会直接报错，统一用空格缩进。

   代码块
      冒号之后、由统一缩进包裹的一组代码，是分支、循环内部要执行的整套语句。

      **生活类比** —— 定下一条规则（条件）之后，配套要完成的\ **一整套行动清单**，整体归属于这条规则。比如"如果发布高温预警：就发通知、启动应急、安排值班"——这三件事合起来是一个代码块。

      .. code-block:: python

         if temp >= 35:            # 冒号
             print("发通知")       # ↓ 这三行
             print("启动应急")     # ← 就是 temp>=35 的代码块
             print("安排值班")     # ↑

      **易混淆点** —— ① 代码块必须缩进，冒号后若不缩进或缩进不统一会报 ``IndentationError``；② 代码块内可以嵌套代码块，``if`` 里再套 ``for``、``for`` 里再套 ``if``，缩进逐层加深形成嵌套结构。
