第 7 章术语：气象数据分析（一）Pandas
=====================================

配套 :ref:`tut-pandas` 正文使用。每个词条 = 一句话定义 + **生活类比** + **代码示例** + **易混淆点**。阅读前先记住一句话：**Pandas 全在「表」与「筛」二字**——DataFrame 是带标签的二维表，布尔索引是按条件「筛」记录，分组聚合是把表「拆开算再拼回」，而 NaN 就是观测簿上的那个「缺测斜杠」。

.. seealso:: 配套正文：:doc:`/user_guide/data/pandas`　·　配套练习：:doc:`/tutorials/ch07_practice`

.. glossary::

   Series
      Pandas 中最基本的一维数据结构，把一组**数据（values）**与一组**索引（index）**绑定在一起，可容纳任意类型，按位置（``iloc``）或按标签（``loc``）取数。

      **生活类比** —— 一列**贴了姓名贴的座位**。你可以说「我要找坐在第三个的同学」（``s.iloc[2]``），也可以说「我要找小王同学」（``s.loc["小王"]``）——同一排座位，两种叫法都行。

      .. code-block:: python

         import pandas as pd

         s = pd.Series([36.5, 35.2, 38.0], index=["北京", "上海", "广州"])
         print(s.loc["上海"])        # 按标签取：35.2
         print(s.iloc[1])            # 按位置取：35.2
         print(s.values, s.index)    # 底层数组与标签
         print(s.describe())         # 统计描述

      **易混淆点** —— ``Series`` 只能存一组数据（一根轴），而 ``DataFrame`` 至少两根轴；一列座位只是年级名单里的**一列**，是无法自成一张「表」的——只有多列拼起来才是表格。

   DataFrame
      Pandas 中最核心的二维表格型数据结构，可看作多个 ``Series`` 按列拼接而成，不同列可以有不同类型，共享同一套行索引。

      **生活类比** —— 一张**整班座位表**。表的每一列放同一类信息（一列全是姓名、一列全是学号、一列全是气象要素），列与列之间类型可以不同，但整张表共用同一行标签（学号）。气象站点逐日观测就是最典型的 ``DataFrame``——一行一条记录、一列一个要素。

      .. code-block:: python

         df = pd.DataFrame({
             "温度": [18, 22, 26],
             "湿度": [65, 70, 60],
             "风速": [3, 4, 2],
         }, index=["08:00", "12:00", "14:00"])
         print(df["温度"])     # 取一列，返回 Series

      **易混淆点** —— 取**一列**用 ``df["温度"]``（返回 Series）；取**多列**必须 ``df[["温度", "湿度"]]``（双层括号，返回 DataFrame）。单列省略列表会少一层，稍不留神就报 ``KeyError`` 或拿错类型。

   索引 Index
      每一起数据都有**标签**，它对应行索引集合；所谓**数据对齐**，就是算术或合并时 Pandas 自动把标签相同的行放在一起计算。

      **生活类比** —— 索引就是考场上的**准考证号**。数据对齐就是联考时按准考证号把试卷对号入座——学号相同才放一起算，学号不同的绝不混。

      .. code-block:: python

         s1 = pd.Series([100, 101], index=["8点", "9点"])
         s2 = pd.Series([200, 202], index=["9点", "10点"])
         print(s1 + s2)   # 只有 "9点" 有值(301)；"8点"、"10点" 因为对不上号 → NaN

      **易混淆点** —— ``loc`` 按标签取、**含两端**；``iloc`` 按整数位置取、**左闭右开**。写 ``df.loc[0]`` 想取第一行却报错，多半是因为索引不是整数 0 开头——先打印 ``df.index`` 看清楚标签是什么。

   布尔索引
      按**条件真假**筛选数据的核心方法（英文 Boolean Indexing）：对列算出一组 True/False 掩码，只保留真值所在的行，本质是用逻辑条件替代数字下标。

      **生活类比** —— 农业气象里的**震动筛子**。你有一堆逐日观测（谷物），只想看「高温日」（温度 > 35℃）——布尔索引就是那个筛眼，条件「温度 > 35」先生成一个 True/False 判断（每颗谷物过不过得了筛孔），只有为真的行才落进筛子里，其余全部过滤掉。

      .. code-block:: python

         df = pd.DataFrame({
             "温度": [28, 36, 39, 22, 33],
             "湿度": [60, 55, 70, 80, 45],
             "风速": [3, 5, 2, 4, 6],
         }, index=["周一", "周二", "周三", "周四", "周五"])

         hot_days = df[df["温度"] > 35]                     # 高温日：周二、周三
         print(hot_days)
         alert = df[(df["温度"] > 38) | (df["风速"] > 5)]   # 高温或大风：周三、周五
         print(alert)

         df.loc[df["温度"] > 35, "高温标志"] = 1            # 安全地给高温日打标

      **易混淆点** ——
      - 必须用按位 ``&``（且）/``|``（或）/``~``（非）且每个条件加圆括号，关键字 ``and``/``or`` 在此直接报 ``ValueError``；
      - ``df[df["温度"] > 35]`` 筛的是**行**，``df[["温度", "湿度"]]`` 筛的是**列**，别把单双层括号搞混；
      - 筛选后要改值请走 ``df.loc[条件, 列] = ...``，直接 ``df[df["温度"] > 30]["湿度"] = 50`` 会触发 ``SettingWithCopyWarning``（改的可能是临时副本）；
      - 筛选「含『雨』的天气现象」用 ``df["天气"].str.contains("雨")``，而不是 ``== "雨"``。

   分组聚合
      遵循「拆分—应用—合并」（Split-Apply-Combine）范式（英文 GroupBy & Aggregation）：先按一列或多列把数据拆成若干组，再对每组各自聚合（求均值、极值、计数等，把多行压成一行摘要），最后合并回一张新表。

      **生活类比** —— 气象中心汇总全国数据。你有一沓 100 个站点、10 年的逐日记录，要算「各站年平均气温」：先把属于兰州站的纸张抽出来放一堆、北京站的放另一堆……（**拆分**）；每堆分别加总除以天数（**应用聚合**）；最后得到一张只有站点列表和各站年平均温的汇总表（**合并**）。

      .. code-block:: python

         df = pd.DataFrame({
             "站点": ["A", "A", "B", "B", "A", "C"],
             "年份": [2020, 2021, 2020, 2021, 2022, 2020],
             "温度": [18, 19, 15, 16, 20, 22],
             "降水": [100, 120, 80, 90, 110, 60],
         })
         print(df.groupby("站点")["温度"].mean())          # 各站平均温度
         result = df.groupby("站点").agg({                 # 多列多聚合
             "温度": ["mean", "max"],
             "降水": "sum",
         })
         print(result)
         df["距平"] = df.groupby("站点")["温度"].transform(lambda x: x - x.mean())

      **易混淆点** ——
      - ``df.groupby("站点")`` 返回的只是**惰性的计划对象**，直接 ``print`` 只见内存地址，必须紧跟 ``.mean()``/``.agg()`` 才真正执行；
      - 聚合（.mean）行数**变少**；``transform`` 行数**不变**（把组内统计广播回每一行，常用于在原表加一列「该站平均值」）；
      - 分组列默认成为新表索引，想保留为普通列用 ``as_index=False`` 或 ``.reset_index()``，否则后续按它筛选会 ``KeyError``。

   透视表
      把「长格式」数据重塑成「宽格式」汇总工具（英文 pivot_table）：取一个（或多个）键做行索引、取一个键做列标签，在交叉格子上执行聚合（求和、平均、计数）。

      **生活类比** —— 把原始流水账变成**气象要素时空分布表**。原始数据是逐条流水「A站 1月 气温 5 度」「B站 1月 气温 4 度」……透视表把「站名」放行标题、「月份」放列标题，交叉格子里自动填上该站该月的值——一眼横向比站点差异、纵向比季节演变。

      .. code-block:: python

         df = pd.DataFrame({
             "站点": ["A", "A", "B", "B", "A", "B"],
             "月份": [1, 2, 1, 2, 3, 3],
             "温度": [5, 7, 4, 6, 8, 9],
             "降水": [20, 30, 10, 25, 35, 15],
         })
         pivot = df.pivot_table(       # 行=站点，列=月份，值=平均温度（默认 mean）
             index="站点", columns="月份", values="温度")
         pivot_adv = df.pivot_table(
             index="站点", columns="月份", values=["温度", "降水"],
             aggfunc="sum", margins=True, margins_name="合计")
         print(pivot_adv)

      **易混淆点** ——
      - 用 ``pivot`` 遭遇重复（同一组 index+columns）会报 ``ValueError``；**气象原始数据几乎必有重复**，所以一律用 ``pivot_table``（内部自动聚合）；
      - ``df.pivot_table(index="站点", columns="月份", values="温度")`` 等价于 ``df.groupby(["站点", "月份"])["温度"].mean().unstack()``，但透视表写法更直观；
      - ``margins=True`` 的合计行用的是与 ``aggfunc`` 相同的算法：``aggfunc="mean"`` 时合计行是「整体均值」，而不是「各月均值的平均」。

   NaN（缺失值标记）
      NaN（Not a Number，非数）是 Pandas/NumPy 表示数值缺失的标准占位符。它的核心特性是「传染性」：任何含 NaN 的算术结果仍是 NaN；某列一旦出现 NaN，整列 dtype 会被从 int 提升为 float64。

      **生活类比** —— 观测簿上的**缺测章**。某天自动站通信中断、温度记录空白，记录员画一个斜杠「 / 」——这既不是 0℃（0 度是有效观测，代表冰点），也不是「还没记」，而是「本条记录不存在」。在 Pandas 里，NaN 就是这个斜杠。

      .. code-block:: python

         import numpy as np

         df = pd.DataFrame({"温度": [22, 28, np.nan, 25, 19],
                            "湿度": [65, np.nan, 70, 55, 60]})
         print(df.isna())                       # True/False 缺测矩阵
         df["温度"].fillna(df["温度"].mean(), inplace=True)   # 用历史均值填补
         df["湿度"].fillna(method="ffill", inplace=True)      # 用上一条记录向前填充

         df_clean = df.dropna()                 # 删除含 NaN 的行
         df_temp = df.dropna(subset=["温度"])   # 只删温度缺测的行
         df.replace(-9999, np.nan, inplace=True)  # 常见气象缺测值 → NaN

      **易混淆点** ——
      - ``np.nan == np.nan`` 结果是 ``False``——绝不要用 ``df[df["温度"] == np.nan]`` 筛缺测，必须用 ``pd.isna(df["温度"])`` 或 ``np.isnan()``；
      - 气压原本是整数列，一处缺测会让整列悄悄变成 ``float64``；
      - ``df["温度"].sum()`` 默认跳过 NaN（``skipna=True``），会悄悄漏掉缺测；若单站缺测率超过 5%，应先插补或标记再算统计量，否则结果代表性不足。

速记对照表
----------

网格表把最易混的词条放一起对照记忆：

.. list-table:: Pandas 速记对照表
   :header-rows: 1

   * - 对象
     - 说白了是什么
     - 一句话记忆
   * - ``Series``
     - 一列带标签的数据
     - 一列名单，能按座次也能按名字
   * - ``DataFrame``
     - 多列拼成的二维表
     - 一张表，多列要素
   * - ``索引 Index``
     - 行标签集合；数据对齐按标签匹配
     - 学号对上才放一起算
   * - ``布尔索引``
     - 按条件真假筛行
     - 筛子只放 T 的记录
   * - ``groupby``
     - 拆分—应用—合并
     - 先分堆、再算、再拼回
   * - ``pivot_table``
     - 长表变矩阵汇总
     - 站位 × 时间一目了然
   * - ``transform``
     - 组内统计广播回每一行
     - 行数不变加一列
   * - ``NaN``
     - 观测簿上的缺测斜杠
     - 是缺测，不是 0
   * - ``&`` / ``|``
     - 多条件「且 / 或」
     - 每个条件记得加括号

.. note:: 最值得记的一条

   所有取数前先问自己：这是**标签**还是**位置**？——标签式取数 ``loc`` 和 ``sel`` 含两端，位置式取数 ``iloc`` 和 ``isel`` 左闭右开。顺序一认错，边界就错一整天。
