三大模块速览
------------

- **模块一 Python 编程基础** （第 1-5 节）：Conda、数据类型、分支循环、函数与作用域、面向对象与高级语法。
- **模块二 气象数据处理** （第 6-8 节）：NumPy、Pandas、Xarray。
- **模块三 气象数据可视化** （第 9-10 节）：Matplotlib、Cartopy。
